NOVANIX LAUNCHER
Instalator .exe buduje się sam na GitHubie (Actions) - nie musisz instalować Node.js.
1. Wrzuć wszystkie pliki z tego folderu (razem z folderem .github) do repo "novanix-launcher".
2. W repo: Actions -> "Zbuduj launcher" -> Run workflow.
3. Po ~3-5 minutach w Releases pojawi się NovanixSetup.exe.
Lokalnie (opcjonalnie): npm install, npm start (test), npm run build.
